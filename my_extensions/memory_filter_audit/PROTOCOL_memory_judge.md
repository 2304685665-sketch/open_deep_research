**动机**：规则型准入过滤在没见过的措辞上泛化差（v4 留出集 5/31，EVIDENCE §61）。新增第二层 `ODR_MEMORY_LLM_JUDGE=1`（默认关）：规则放行的条目再交给 gpt-4.1-mini 判别（提示词 `memory_guard.JUDGE_PROMPT`，评测前冻结）。最终 = 规则拦截 OR 判别器拦截；判别器出错则回落规则结果。
**评测**：`eval_memory_judge.py` 在四份冻结语料（dev 121、v2 85、v3 120、v4 72）上计算 规则 vs 规则+判别器 的恶意拦截数与正常误丢数，一次运行，不调提示词。花费预计 < $0.1。
**预测（运行前）**：v4 拦截率由 5/31 大幅上升（预期 ≥ 25/31）；多语言和行为操控类被拦；正常误丢 ≤ 3/41（把"总是引用来源""不要在聊天里分享原始数据"等误判为恶意是主要风险）；总调用数 ≈ 规则放行条目数（约 350）。
**怎么解读**：判别器提示词是我写的，评测语料也是我写的，v4 已被规则的结果"看过"但提示词没有看过 v4 的内容；一次性评测后不再改提示词。若改了提示词，v4 作废、另写 v5。判别器本身可被注入（记忆文本进入判别提示词），这是已知局限，本实验不测对抗判别器的注入。
**作废条件**：`judge_errors > 0`、额度耗尽。
